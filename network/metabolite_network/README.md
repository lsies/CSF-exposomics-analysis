# Differential metabolite-driven network analysis

Install requirements.txt and run `python run_analysis.py`. To regenerate figures only, run `python run_analysis.py --figures-only`. Individual network plots can be generated using `python code/plot_PPI.py` and `python code/plot_KYNU.py`.

The default workflow uses archived database responses and external analysis outputs. It rebuilds metabolite mapping, STRING coverage, expression integration, network summaries, enrichment tables and figures without submitting data to a server.

`raw/study` contains the feature annotations and comparison statistics required by this network workflow. These are precomputed upstream inputs. The code checks the comparison-level BH adjustment and selects differential features from the supplied statistics.

`raw/public` contains source database responses, Metascape outputs and their metadata. `raw/cytoscape` contains plugin outputs and parameters. `data` contains harmonized inputs, foreground/background lists, expression inputs and figure source data. `results` contains regenerated mapping, statistics, enrichment tables and GraphML networks. `figures` contains PDF, SVG, PNG and TIFF exports. `reports/validation_checks.csv` is generated by the final validation step.

Metascape enrichment and Cytoscape plugin calculations were performed externally. The workflow reads these outputs and does not implement the Metascape server or reproduce the CytoNCA/cytoHubba graphical interfaces. Changed input gene lists require new external analyses. Frozen input checks prevent reusing archived outputs with changed inputs.

Adjusted P values are read from the original Metascape outputs. They are not recalculated from the filtered returned-term tables. Separate GO-BP, GO-CC, GO-MF and KEGG analyses are retained.

The complete PPI GraphML includes isolated genes. The PPI figure displays the connected network. The KYNU figure uses typed biochemical reaction and pathway annotation edges. Gene membership, network topology and enrichment significance are represented by their corresponding source data.

The standalone Step 5 module is excluded from this release. The files `data/step5_all_gene_response.csv.gz` and `data/step5_eligible_analysis_sets.csv` are archived statistical inputs for the Step 6 integration and figures. They are used locally and do not require a separate public-expression module.
